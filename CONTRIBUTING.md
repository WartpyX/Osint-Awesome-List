# Contributing

Thanks for wanting to contribute! The goal is a **small, high-quality** list, not a big empty one. Fewer tools, each one properly described.

## What we accept

- A tool or source **you've personally tried** and that works.
- A clear use in OSINT.
- Arabic or regional (MENA) sources are a **priority**.
- Public, lawful data only.

## What we don't accept

- Tools that violate privacy or enable stalking, blackmail, or hacking.
- Dead or abandoned tools.
- Marketing or affiliate links.
- Duplicates with no clear difference from an existing entry.
- Copyright-infringing content.

## Entry format

```
- [Tool name](https://link) 🆓 - What it does and when to use it. A note on limits.
```

Legend: 🆓 Free · 💰 Paid · 🔑 Free with account · 🧰 Open source / CLI

## Writing rules

1. One to two lines, no more.
2. State the **real limitation** or downside, not just praise.
3. No marketing words like "best" or "amazing".
4. Keep ordering consistent within the section (alphabetical or by importance).
5. Link to the official site or original repo.
6. Add the English entry to `README.md` and the Arabic entry to `README.ar.md`. If your Arabic isn't strong, add the English one and we'll help with the translation.

## Pull request steps

1. Fork the repo and create a new branch.
2. Add your entry in the right section.
3. Open a Pull Request and fill in the template.
4. The GitHub Action checks links automatically. It must pass.

## Reporting a dead link

Open an Issue using the "Dead link" template, or send a PR removing it.
